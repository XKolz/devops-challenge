    Jenkins CI/CD Setup

    The Jenkinsfile at the project root defines the same pipeline as GitHub Actions: Checkout → Test → Build → Push to ECR → Deploy to EC2

    Start Jenkins (Docker)

    cd jenkins
docker compose up -d

    Jenkins will be available at http://localhost:8080

    Get the initial admin password:

    docker exec jenkins-jenkins-1 cat /var/jenkins_home/secrets/initialAdminPassword

    First-time Setup

    1. Open http://localhost:8080 and paste the admin password
    2. Click Install suggested plugins and wait for it to finish
    3. Create your admin user
    4. Install one extra plugin: Manage Jenkins → Plugins → Available
    5. Search and install: SSH Agent Plugin
    6. Restart Jenkins after install

    Add Credentials

    Go to Manage Jenkins → Credentials → System → Global credentials → Add Credential

    Add these 5 credentials exactly as shown:

    Kind ID Value
    Secret text AWS_ACCESS_KEY_ID Your IAM access key
    Secret text AWS_SECRET_ACCESS_KEY Your IAM secret key
    Secret text ECR_REGISTRY 816880416872.dkr.ecr.us-east-1.amazonaws.com
    Secret text EC2_HOST 18.212.128.34
    SSH Username with private key EC2_SSH_KEY Username: ec2-user, paste contents of ~/.ssh/devops-challenge-key.pem

    Create the Pipeline

    1. New Item → Pipeline → name it devops-challenge
    2. Under Pipeline:
    3. Definition: Pipeline script from SCM
    4. SCM: Git
    5. Repository URL: https://github.com/XKolz/devops-challenge
    6. Branch: */main
    7. Script Path: Jenkinsfile
    8. Click Save

    Run the Pipeline

    Click Build Now. The pipeline runs through 5 stages:

    Checkout → Test → Build → Push to ECR → Deploy

    Watch progress under Console Output.

    Pipeline Stages Explained

    Stage What it does
    Checkout Clones the repo from GitHub
    Test Installs Python deps and runs pytest
    Build Builds Docker image tagged with short Git SHA
    Push to ECR Authenticates to ECR and pushes SHA + latest tags
    Deploy SSHes into EC2, pulls new image, restarts container

    Stop Jenkins

    cd jenkins
docker compose down

    Data is persisted in the jenkins_home Docker volume — your config and build history survive restarts.
