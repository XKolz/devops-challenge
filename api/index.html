    API Reference

    Base URL (local): http://localhost:8000
    Base URL (production): http://<EC2_HOST>

    Interactive docs (Swagger UI): <base-url>/docs
    OpenAPI schema: <base-url>/openapi.json

    GET /health

    Health check. Returns immediately with no dependencies.

    Response 200 OK

    {"status": "healthy"}

    Example

    curl http://localhost:8000/health

    GET /items

    List all items in the store.

    Response 200 OK — array of item objects (empty array if none exist)

    [
  {
    "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "name": "Widget",
    "description": "A sample widget",
    "price": 9.99
  }
]

    Example

    curl http://localhost:8000/items

    POST /items

    Create a new item. name and price are required; description is optional.

    Request body

    {
  "name": "Gadget",
  "description": "Optional description",
  "price": 4.99
}

    Response 201 Created

    {
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "Gadget",
  "description": "Optional description",
  "price": 4.99
}

    Example

    curl -X POST http://localhost:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "Gadget", "price": 4.99}'

    GET /items/{item_id}

    Fetch a single item by its UUID.

    Path parameter: item_id — UUID string returned by POST /items

    Response 200 OK

    {
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "Gadget",
  "description": null,
  "price": 4.99
}

    Response 404 Not Found — if the ID does not exist

    {"detail": "Item not found"}

    Example

    curl http://localhost:8000/items/3fa85f64-5717-4562-b3fc-2c963f66afa6

    Data model

    Item
├── id          string (UUID v4, assigned by server)
├── name        string (required)
├── description string | null (optional)
└── price       number (required, float)

    In-memory store

    Items are stored in a Python dict and are lost when the container restarts. This is intentional for the challenge scope — production would use a persistent database.
