    Deployment Guide

    Prerequisites

    • [ ] Terraform ≥ 1.5 installed (terraform -version)
    • [ ] AWS CLI installed and configured (aws configure)
    • [ ] IAM user with EC2, VPC, ECR, IAM, CloudWatch permissions
    • [ ] An existing EC2 key pair in the target region
    • [ ] GitHub repository with Actions enabled

    Step 1 — Provision infrastructure

    cd terraform

terraform init

# Preview what will be created
terraform plan -var="key_name=<your-key-pair-name>"

# Apply (creates ~10 resources, takes ~1 min)
terraform apply -var="key_name=<your-key-pair-name>"

    Note the outputs printed at the end:

    ec2_public_ip      = "54.123.45.67"
ecr_repository_url = "123456789.dkr.ecr.us-east-1.amazonaws.com/devops-challenge-prod"
vpc_id             = "vpc-0abc123"

    Step 2 — Configure GitHub Secrets

    Go to your repo → Settings → Secrets and variables → Actions → New repository secret.

    Secret name Value
    AWS_ACCESS_KEY_ID IAM access key (needs ECR push + describe permissions)
    AWS_SECRET_ACCESS_KEY IAM secret key
    EC2_HOST The ec2_public_ip from Terraform output
    EC2_SSH_KEY Full contents of your .pem private key file

    Paste the PEM key

    Open the .pem file, copy everything including the -----BEGIN RSA PRIVATE KEY----- header and footer, and paste it as the secret value.

    Step 3 — Update ECR repository name in the workflow

    If you used non-default Terraform variable values, update ECR_REPOSITORY in .github/workflows/ci-cd.yml to match:

    <app_name>-<environment>   →   devops-challenge-prod  (defaults)

    Step 4 — Trigger the pipeline

    git add .
git commit -m "initial deployment"
git push origin main

    Watch the pipeline at Actions → CI/CD Pipeline.
    Jobs run in order: build-and-test → push-to-ecr → deploy.

    Step 5 — Verify

    curl http://<ec2_public_ip>/health
# {"status":"healthy"}

    Rollback

    Each image is tagged with its Git SHA. To roll back to a previous version:

    1. Find the SHA of the last good commit: git log --oneline
    2. In GitHub Actions → CI/CD Pipeline → find the run with that SHA → re-run the deploy job only.

    Or SSH into the instance and pull a specific tag manually:

    ssh -i <key.pem> ec2-user@<EC2_HOST>
docker stop app && docker rm app
docker run -d --name app --restart unless-stopped -p 80:8000 \
  <ecr_url>:<git-sha>

    Tear down

    cd terraform
terraform destroy -var="key_name=<your-key-pair-name>"

    This removes all AWS resources created by Terraform. The ECR repository and all images will be deleted.
