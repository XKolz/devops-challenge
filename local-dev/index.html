    Local Development

    Prerequisites

    • Docker Desktop running
    • (Optional) Python 3.11 if you want to run tests without Docker

    Start the app

    docker compose up --build

    The API is live at http://localhost:8000.
    Interactive Swagger UI: http://localhost:8000/docs

    The app/ directory is volume-mounted, so changes to Python files reload the server automatically (Uvicorn --reload is active inside the container via the volume mount).

    Run tests locally

    pip install fastapi uvicorn pydantic pytest httpx
pytest app/tests/ -v

    Expected output:

    app/tests/test_main.py::test_health PASSED
app/tests/test_main.py::test_list_items_empty PASSED
app/tests/test_main.py::test_create_item PASSED
app/tests/test_main.py::test_get_item PASSED
app/tests/test_main.py::test_list_items_after_create PASSED
app/tests/test_main.py::test_get_nonexistent_item PASSED

    Try the API with curl

    # Health check
curl http://localhost:8000/health

# Create an item
curl -X POST http://localhost:8000/items \
  -H "Content-Type: application/json" \
  -d '{"name": "Widget", "description": "A test item", "price": 9.99}'

# List all items
curl http://localhost:8000/items

# Get by ID (use the id returned from the POST above)
curl http://localhost:8000/items/<id>

    Stop the app

    docker compose down
