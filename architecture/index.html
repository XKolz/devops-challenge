    AWS resource map

    Resource Name pattern Purpose
    VPC {app}-{env}-vpc Isolated network (10.0.0.0/16)
    Internet Gateway {app}-{env}-igw Public internet access
    Public subnet {app}-{env}-public-subnet EC2 host subnet (10.0.1.0/24)
    Route table {app}-{env}-public-rt Routes 0.0.0.0/0 → IGW
    Security group {app}-{env}-sg Inbound 22, 80, 443; all egress
    IAM role {app}-{env}-ec2-role AmazonEC2ContainerRegistryReadOnly
    EC2 t3.micro {app}-{env} Runs the Docker container
    ECR repository {app}-{env} Private Docker image store
    CloudWatch log group /aws/ec2/{app}-{env} 7-day retention
    CloudWatch alarm {app}-{env}-cpu-high CPU > 80% for 4 min

    Security notes

    • The EC2 instance has no stored AWS credentials. It authenticates to ECR via the IAM instance profile — credentials are fetched from the instance metadata service at deploy time.
    • Port 22 is open to 0.0.0.0/0 to allow GitHub Actions runners (dynamic IPs) to SSH in. In a hardened setup this would be replaced with AWS SSM Session Manager (no port 22 at all).
    • The container listens on port 8000; the host maps it to port 80. Port 443 is open in the security group but no TLS termination is configured (see Limitations in the README).
